# RPI 技能

通用 RPI（调研、计划、实施、迭代）技能，面向任何支持技能机制的 AI 工具。

## 这个技能解决什么问题

当任务复杂、风险高、上下文不完整时，RPI 帮你把执行拆成四个阶段，降低返工和失控风险。

## 快速使用

1. 在工具里启用 `rpi` 技能。
2. 给出任务目标，让模型先执行 `调研`。
3. 查看 `计划` 并确认后，再进入 `实施`。
4. 完成后要求执行 `迭代`，输出改进优先级。

## 推荐提示词

```text
请使用 $rpi 处理这个任务，严格按 调研 -> 计划 -> 实施 -> 迭代 四阶段执行。
在调研和计划阶段不要改代码；实施阶段每次改动后都给出验证结果；最后在迭代阶段给出按优先级排序的改进建议。
```

## 阶段产物

- 调研：概要 / 关键发现 / 上下文 / 待确认问题 / 建议
- 计划：目标 / 前提假设 / 范围与涉及文件 / 执行步骤 / 风险与缓解 / 验证方案
- 实施：已完成改动 / 验证结果 / 偏离说明 / 剩余工作
- 迭代：优点 / 问题 / 边界情况与缺口 / 优先级改进项
